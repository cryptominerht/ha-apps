# Home Assistant apps

## Add to Home Assistant

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fcryptominerht%2Fha-apps)

Or manually: **Settings → Apps → Install app → ⋮ → Repositories**, then paste
`https://github.com/cryptominerht/ha-apps` and click **Add**.

## Apps

| App | What it does |
|---|---|
| [TV Kid Lock](tv_kidlock) | Pauses a Samsung TV after a set watch time, blocks its internet via UniFi, and shows a quiz in the TV browser until it's answered |

Settings, questions and results live in Home Assistant (`app_configs`), not in this repo.
